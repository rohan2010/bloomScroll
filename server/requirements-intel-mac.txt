# Python packages for the local Laya server on an INTEL Mac. Use Python 3.11 (3.10 also works).
#
# Why a separate, fully pinned file:
#   - PyTorch stopped publishing Intel-Mac builds after 2.2.2.
#   - transformers 5.x needs a newer torch, so 4.57.6 (the last 4.x) is pinned; Laya's checkpoints
#     load on it unchanged. This is Laya's own documented fix for Intel Macs.
#   - torch 2.2.2 was built against NumPy 1.x and crashes with NumPy 2.
#   - torch 2.2.2's compiler doesn't run on Python 3.12+, and Laya's model code needs it at
#     import time, so Python 3.12 fails with "Dynamo is not supported on Python 3.12+".
# These exact versions were verified on a 2017 MacBook Pro (i5-7360U, macOS 13, Python 3.11.11).
#
# Easiest: run ./setup.sh from the repo root. By hand:
#   /usr/local/bin/python3.11 -m venv server/.venv
#   server/.venv/bin/python -m pip install -r server/requirements-intel-mac.txt
